## What Was Done

Built `scripts/enrich-facts-from-sources.ts` — a zero-LLM enrichment tool that fetches real public data per source type:

| Source Type | API | Data Fetched |
|-------------|-----|-------------|
| `code` | GitHub REST API | Stars, forks, language, topics, license, issues, created date |
| `academic` | arXiv Atom API | Title, authors, abstract, published date, categories |
| `ai-ecosystem` | HuggingFace Hub API | Downloads, likes, tags, pipeline, license, last modified |
| `culture-art` | Met Museum API | Artist, title, date, medium, dimensions, culture, object URL |
| `dev-community` | HTTP fetch + HTML | Page title, meta description, headings, links |

**Features**:
- `--force` flag: clears cache, re-fetches all
- `--offline` flag: only uses cached data
- Idempotent: skips if cache valid and not forced
- Cache stored in `metadata/source-data-cache.json`
